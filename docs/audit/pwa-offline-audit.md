Bundled content (doctrine, supplemental) is seeded into IndexedDB via `ensureStorageReady` and survives offline because IndexedDB is local storage, not network-dependent.

Sermons are synced from the network but the sermon index is stored in IndexedDB once loaded. Sermon detail requires either saving for offline or fetching the body from cache.

## 7. Offline Sermons

| Check | Result |
|---|---|
| Sermon list | ✅ Shows "All sermons" with cached index |
| Synced sermon detail | ✅ 10 sermons available — their index data is in IndexedDB |
| Full body for cached sermons | Depends on whether `saveSermonForOffline` was called |
| Unsaved sermon detail | Shows summary + "Connect to load this sermon" if not cached |

Sermon behavior:
- The sermon **index** (title, summary, author, date) is always available offline because it's stored in IndexedDB after sync.
- The full sermon **body** requires either: (a) explicit "Save offline" action, or (b) fetching detail while online.
- Sermon detail page renders the cached body when available, or falls back to the summary with an offline message.
