# TOTJO Holocron v2 v0.1.0

## Release notes

### What's new since the private prototype

**Visual identity**
- Retro sci-fi terminal skin with scanline overlays, double borders, corner brackets, and ambient cyan/amber glow
- Skeuomorphic hardware depth: recessed panel bevels, raised buttons, corner screws/rivets, panel seams, brushed-metal texture, status LEDs, data plate rails
- Dark, light, and system appearance preference (three-way theme persisted to localStorage, inline script prevents flash of unstyled content)

**Data safety**
- Markdown export of notes, bookmarks, and practice history
- JSON backup with restore preview (dry-run only — does not write data)
- Persistent storage request to reduce eviction risk
- Backup freshness reminders in Settings
- All user data stays in the browser (IndexedDB + localStorage)

**Offline and PWA**
- Service worker precaches app shell (41 entries, ~1393 KiB)
- Offline banner when network is unavailable
- App update prompt when new service worker is waiting
- Visibility-based update check (checks on tab becoming visible)
- Hourly update polling
- Build marker visible in Settings > About & Legal
- Documented safe cache reset procedure (unregister SW + clear Cache Storage only — does not wipe IndexedDB or localStorage)

**Meditation timer**
- Configurable duration, cue modes (start/end/custom interval), and bell sounds
- Screen Wake Lock keeps device awake during active sessions (best-effort)
- Session history persisted to IndexedDB
- Timer controls work offline

**Reading and library**
- Local-first doctrine reader with bookmarking and notes
- Code view, font scale, theme, and contrast controls
- Sermon sync from remote feed
- Search across doctrine, supplemental, sermons, and bookmarks

**Accessibility**
- All meaningful text in both themes meets WCAG contrast thresholds (verified by automated checker)
- Focus outlines visible over bevels, glows, and shadows
- 320px reflow: bottom nav compacts, no horizontal overflow
- `prefers-reduced-motion` disables all transitions
- `forced-colors: active` hides decorative elements

### Known limitations

- Restore applies (writing data from a backup) is not implemented — preview only
- Sync to Supabase is present but disabled by default (future release)
- Social features, Web Push, and collaborative tools are not included
- Announcement feed validation workflow cannot be pushed automatically (requires manual step with workflow-scoped PAT)

### Upgrade notes

No migration is needed — all user data is stored in IndexedDB and localStorage and is preserved across updates. If the app doesn't show the latest visual changes after an update, follow the safe cache reset procedure:

1. Open DevTools → Application → Service Workers → Unregister
2. Open DevTools → Application → Cache Storage → Delete all `workbox-*` caches
3. Reload the page

This does not clear IndexedDB (notes, bookmarks, practice history) or localStorage (settings, theme preference).
