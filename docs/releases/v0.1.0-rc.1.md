- Mobile-first app shell with stable navigation.

## Known limitations

- Unsaved sermon bodies are not guaranteed offline. Sermon index (title, summary, author, date) is available after sync; the full body requires an explicit Save offline action or a prior cached fetch.
- Real mobile install prompt behavior should still be manually verified outside headless automation.
- RC status means fixes may still land before final v0.1.0.

## Final smoke checklist

From the tag `v0.1.0-rc.1`:

1. `git clone` or `git checkout v0.1.0-rc.1`
2. `pnpm install`
3. `pnpm typecheck`
4. `pnpm build`
5. `pnpm test`
6. `pnpm preview`
7. Open `/daily` — dashboard renders with timer and quick lanes
8. Start and stop the dashboard meditation timer
9. Open `/library` — search works, section links visible
10. Search for "tenets" — doctrine results appear
11. Open The Three Tenets — reader renders with settings gear
12. Open reader settings gear — panel opens
13. Open `/library/sermons` — sermon list renders
14. Open a sermon — body renders (requires online for uncached)
15. After app shell is cached, test offline reload
16. Verify settings persist after browser reload
