# TOTJO Holocron v0.1.1

v0.1.1 is a security maintenance release for v0.1.0.

## Security and dependency maintenance

- Fixed all production dependency audit findings.
- `pnpm audit --prod` now reports 0 vulnerabilities.
- Updated `react-router-dom` from 7.14.2 to 7.18.1 (fixes DoS and CSRF advisories).
- Updated `@supabase/supabase-js` from 2.104.1 to 2.108.2 (fixes `ws` memory exhaustion and disclosure advisories).
- Updated Vite, React, and related development/build dependencies.
- Documented remaining `serialize-javascript` alerts as build-time only and not shipped in `dist/`.

## Validation

- `pnpm audit --prod`: 0 vulnerabilities
- `pnpm check:announcements`: pass
- `pnpm check:theme-contrast`: 22/22 WCAG pairs pass
- `pnpm typecheck`: pass
- `pnpm build`: 41 entries, 1408 KiB
- `pnpm test` (×2): 42 files, 240 tests, pass

## Notes

No product behavior changes are intended in this release. The visual theme, data safety, offline support, timer, reading, and all user-facing features are unchanged from v0.1.0.
