# TOTJO Holocron v2 v0.1.0-rc.3

## Status

Release candidate 3, based on v0.1.0-rc.2.  
No known product blockers.

---

## Improvements since v0.1.0-rc.2

- Runtime-configurable external announcement feed URL via `public/runtime-config.json`
- Announcement feed validator script (`pnpm check:announcements`)
- External announcement feed publishing without app redeploy
- Browser support tiers and progressive enhancement policy documented
- Persistent storage status display and "Protect data" button in Settings
- JSON backup export (notes, bookmarks, practice history, downloads, settings)
- Backup freshness reminders in Settings (never backed up / fresh / stale)
- JSON restore preview UI in Settings — parse, validate, preview counts, no mutation
- Cross-browser data safety: all export/backup flows use Blob download + file input

## Known limitations

- Restore apply (merge/import) is not yet implemented. Preview is non-mutating.
- Browser storage is not a substitute for backups. Users should export Markdown or JSON periodically.
- Advanced PWA features (persistent storage, app badge, file picker) vary by browser.
- Unsaved sermon bodies are not guaranteed offline.
