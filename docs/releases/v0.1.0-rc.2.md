## Improvements since v0.1.0-rc.1

- Clarifies sermon offline availability language (saved offline / needs connection / read sermon).
- Adds desktop and tablet TOTJO brand mark (inline SVG logo + "TOTJO" label in app nav).
- Adds Markdown user-data export for notes, bookmarks, practice history, timer defaults, and reader settings.
- Documents user-data export architecture (`docs/architecture/user-data-export.md`).
- Adds Settings User Data section with Export Markdown button and storage persistence note.
- Adds persistence guardrails around user-created data — bootstrap only touches documents table, not user tables.

## Known limitations

- Browser storage can still be cleared by the user or the browser under storage pressure. Export is the user-owned backup path.
- Explicit "Save offline" remains the durable user intent for sermon bodies, even if previously fetched sermons may be available locally.
- Unsaved sermon bodies are not guaranteed offline.
