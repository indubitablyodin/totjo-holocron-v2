# TOTJO Holocron v0.1.7

v0.1.7 is a UX remediation and navigation maintenance release focused on making the classic
instrument-panel interface easier to use without flattening its oldschool character.

## User experience

- Added measured mobile dock clearance so Focus, Timer, and reader controls remain reachable above
  the fixed navigation pill.
- Reordered Timer actions so the primary Start timer control appears before advanced settings and
  secondary actions on phones.
- Removed the empty Focus page heading and made Daily Focus expose one meaningful page heading.
- Replaced the icon-only Timer defaults affordance with a visible text-bearing control.
- Tightened wide-screen catalog/listing density while preserving the recessed Timer well and narrow
  long-form reading layouts.
- Made Sermons loading, empty, offline, successful-sync, and failed-sync messages state-specific.
- Fixed mobile Back history across consecutive route changes and made Back visibly unavailable at
  the Focus root when no prior in-app route exists.

## Validation

- Full unit and policy suite: 301 tests passed.
- TypeScript and lint checks passed.
- Phone and desktop shell browser checks passed, including mobile Back regression coverage.
- Local manual acceptance covered light, dark, high-contrast, phone, tablet-like, and desktop
  browser states with no browser console errors observed.

## Notes

- The app remains local-first; no data migration or server API change is included.
- Existing bundle-size and service-worker chunking warnings remain non-blocking and are tracked
  separately from this UX release.
