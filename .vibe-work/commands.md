## Testing with Test Auth

Test auth is automatically enabled when:
- `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` are NOT set, AND
- Hostname is `localhost` or `127.0.0.1`

**Force test auth:**
```bash
VITE_AUTH_TEST_MODE=true pnpm dev
```

**Test sync with test auth:**
```bash
VITE_AUTH_TEST_MODE=true VITE_AUTH_SYNC_ENABLED=true pnpm dev
```

Then use the test sync API:
```bash
# Save profile
curl -X PUT http://localhost:5173/api/test-sync/profile \
  -H "Content-Type: application/json" \
  -d '{"userId": "test-user:user@example.com", "profile": {"some": "data"}}'

# Load profile
curl http://localhost:5173/api/test-sync/profile?userId=test-user:user@example.com

# Clear profile
curl -X DELETE http://localhost:5173/api/test-sync/profile?userId=test-user:user@example.com
```
